# AstraMedia — очередь публикаций в Дзен

Сервер ai-pdlc кладёт сюда готовые пакеты статей Журнала Astra (astrahelper.ru/journal).
Агент в браузере (расширение Claude в Chrome) забирает их и публикует в канал Astra на dzen.ru.

## Структура

```
dzen/<YYYY-MM-DD>-<slug>/
  article.html   текст статьи для редактора Дзена
  cover.png      обложка (может не быть — тогда без обложки)
  meta.json      заголовок, теги, ссылка на оригинал, статус
```

`meta.json`:

| поле | смысл |
|---|---|
| `title` | заголовок для Дзена |
| `tags` | метаданные статьи; в текущем интерфейсе Дзена не вводятся и в текст не добавляются |
| `canonicalUrl` | оригинал в Журнале |
| `category` | news / updates / guides / cases |
| `status` | `pending` — опубликовать; `published` — уже в Дзене; `archive` — устаревшая новость, не публиковать; `failed` — не получилось, см. `note` |
| `dzenUrl`, `publishedAt` | заполняет агент после публикации |

## Как публиковать (инструкция для агента)

1. `git pull` (ключ и автор коммитов уже настроены в `.git/config` репозитория). Возьми папки со `status: "pending"`, **начиная с самых новых** (по дате в имени папки).
2. Не больше **5 статей за один запуск** — Дзен режет охваты за массовый постинг.
3. Перед публикацией проверь в канале, нет ли уже статьи с таким заголовком: публикации канала — https://dzen.ru/profile/editor/astrahelper/publications (сразу этот адрес, без меню профиля). Есть — ставь `published` со ссылкой на неё, второй раз не публикуй.
4. В Дзен Студии: «Создать» → «Статья».
   - Заголовок — `title` из meta.json.
   - Текст — вставь содержимое `article.html` целиком с оформлением, исключив `h1` (заголовок уже введён отдельно) и служебный блок внизу («Служебное (в Дзен не копировать)…»). Сохрани подзаголовки, списки, выделения и ссылки. Проверь начало, конец и полноту текста после вставки.
     **Быстрый путь:** одной командой сохрани `$AGENT_HOME/outbox/<slug>.html` — `<body>` из `article.html` без `h1` и без блока `.note` — и вставь его в поле текста вводом с параметром `fayl` (одно действие, слово в слово, оформление сохраняется). Не переписывай HTML в аргументы вызова.
   - Обложка — исходный `cover.png`. В проверенном интерфейсе работает добавление изображения первым блоком статьи через «Вставить изображение». Дождись завершения загрузки и сохранения; затем проверь нужную картинку в предпросмотре обложки. Не пытайся загружать файл нажатием на серый заполнитель предпросмотра.
     Загружай с параметром `fayl` (скопируй `cover.png` в `$AGENT_HOME/outbox`) — «Материалы» и `attach_file` не нужны. В окне «Публикация» под полем «Название» показаны миниатюры картинок статьи: обложка — выделенная (оранжевая рамка); проверь, что выделена именно `cover.png`.
   - Теги не вводить: в проверенном 13 октября 2026 года интерфейсе публикации статьи отдельного поля нет. По согласованию с пользователем этот шаг пропускается и не блокирует публикацию. `tags` в meta.json сохранять как метаданные; не добавлять их в текст статьи. Повторно проверять только при изменении интерфейса или по отдельной просьбе.
   - При поручении выполнить этот алгоритм публикуй подготовленную статью сразу, без отдельного запроса подтверждения и остановки на скриншоте: первая кнопка «Опубликовать» открывает окно подготовки, затем проверь заголовок и обложку и нажми финальную кнопку «Опубликовать» внутри окна. После нажатия проверь фактическую страницу и статус. Если в текущем поручении человек явно просит только черновик или остановку перед публикацией, соблюдай это ограничение. Изменение инструкции само по себе не запускает публикацию новых статей.
5. Сразу после публикации обнови `meta.json`: `status: "published"`, `dzenUrl`, `publishedAt` (ISO). Если не вышло — `status: "failed"` и причина в `note`.
6. Коммит и push: `dzen: published <slug>` (по одному коммиту на статью или один на запуск).
7. Последним шагом пришли человеку прямую ссылку на опубликованную статью. Перед этим проверь, что ссылка ведёт на нужную статью. Если коммит или синхронизация не удались, кратко сообщи об этом вместе со ссылкой, не скрывая успешную публикацию. Если публикация не подтверждена, сообщи фактический статус и причину, не выдавая ссылку на черновик за опубликованную статью.

Капча, проверка на бота, разлогин, предупреждение Дзена об ограничениях — **остановись** и сообщи человеку. Не обходи и не повторяй попытки.

Сервер не трогает папки со статусом не `pending` — правки агента не перезапишутся.
