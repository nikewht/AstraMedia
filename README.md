# AstraMedia — очередь публикаций в Дзен

Сервер ai-pdlc кладёт сюда готовые пакеты статей Журнала Astra (astrahelper.ru/journal).
Агент в браузере (расширение Claude в Chrome) забирает их и публикует в канал Astra на dzen.ru.

## Структура

```
dzen/<YYYY-MM-DD>-<slug>/
  article.html   текст статьи для редактора Дзена
  cover.png      обложка (может не быть — тогда без обложки)
  meta.json      заголовок, теги, ссылка на оригинал, статус
```

`meta.json`:

| поле | смысл |
|---|---|
| `title` | заголовок для Дзена |
| `tags` | теги, до 5 штук (берём первые) |
| `canonicalUrl` | оригинал в Журнале |
| `category` | news / updates / guides / cases |
| `status` | `pending` — опубликовать; `published` — уже в Дзене; `archive` — устаревшая новость, не публиковать; `failed` — не получилось, см. `note` |
| `dzenUrl`, `publishedAt` | заполняет агент после публикации |

## Как публиковать (инструкция для агента)

1. `git pull`. Возьми папки со `status: "pending"`, **начиная с самых новых** (по дате в имени папки).
2. Не больше **5 статей за один запуск** — Дзен режет охваты за массовый постинг.
3. Перед публикацией проверь в канале, нет ли уже статьи с таким заголовком. Есть — ставь `published` со ссылкой на неё, второй раз не публикуй.
4. В Дзен Студии: «Создать» → «Статья».
   - Заголовок — `title` из meta.json.
   - Текст — открой `article.html` в браузере, скопируй всё **кроме служебного блока внизу** («Служебное (в Дзен не копировать)…») и вставь в редактор. Форматирование (заголовки, списки) должно перенестись.
   - Обложка — `cover.png`.
   - Теги — из `tags`.
   - Опубликовать.
5. Сразу после публикации обнови `meta.json`: `status: "published"`, `dzenUrl`, `publishedAt` (ISO). Если не вышло — `status: "failed"` и причина в `note`.
6. Коммит и push: `dzen: published <slug>` (по одному коммиту на статью или один на запуск).

Капча, проверка на бота, разлогин, предупреждение Дзена об ограничениях — **остановись** и сообщи человеку. Не обходи и не повторяй попытки.

Сервер не трогает папки со статусом не `pending` — правки агента не перезапишутся.
